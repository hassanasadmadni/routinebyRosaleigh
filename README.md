# Rosaleigh Skin Analysis Tool

A personalised skin analysis and routine recommendation app built for [Rosaleigh Cosmetics](https://www.rosaleigh.co.uk) — a premium tallow-based skincare brand based in the UK.

## About

Developed by **Hassan Madni**, Digital Marketing Manager & Market Research Specialist at Rosaleigh Cosmetics.

This tool guides customers through a short skin quiz and photo analysis to recommend the most suitable Rosaleigh products and bundles for their skin type.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Or with Bun:

```sh
bun install
bun run dev
```
